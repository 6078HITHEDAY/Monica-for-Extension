# GitHub 更新检测与版本规则（2026-10-21）

## 实现

当前扩展开发版本改为 **1.0.101**，同步 package、lockfile 根包和浏览器 manifest。运行时继续从 package 读取版本；构建新增三段数字及各处一致性检查。后续常规版本按 `1.0.102`、`1.0.103` 递增，对应 GitHub 标签 `v1.0.102`。保留已发布 `0.1.x` 记录；没有创建标签、Release、提交或推送。Android、CLI 和 Native Host 版本不变。

设置通用分组新增「检查更新」，点击检查时查询固定官方仓库 `Monica-Pass/Monica-for-Extension` 的 `/releases/latest`。数值比较三段版本；同版本或低版本不会提示更新，草稿、预发布及无法解析的标签不会推荐安装。新版提示提供固定仓库的官方标签链接，不采用上游提供的任意 URL，不渲染 release HTML。

检测显示忙碌、发现新版、未发现更新、暂无发布、限流、超时、断网及无效数据状态。12 秒超时、512KiB 响应限制，离开页面取消请求；不后台轮询、不携带密码库内容或认证凭据，不自动下载或安装。隐私说明已同步。

## 设计

本地 M3E Canvas 项目 `extension-github-update-20261021`，预览了待检查、新版及错误三个状态，使用现有列表和按钮组件；真实 Edge 检查深色桌面及 320px／200% 字体。可编辑草图、完整本地链接及截图仅保留在 `docs/design/github-update-20261021*`，不作为仓库图片交付。
