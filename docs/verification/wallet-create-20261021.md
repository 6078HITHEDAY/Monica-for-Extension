# 新建分类与卡包入口 · 2026-10-21

## 范围

条码从“钱包与其他”移入“账号与安全”；会员卡、积分卡、旅行票证加入钱包新建入口。沿用已接入的 Android 卡包数据结构、字段编辑器与详情，不引入另一套存储类型。中文票证名称与 Android 当前资源一致。

新建入口通过独立初始模板参数打开 identity 编辑器；仅对无既有项目的创建初始化，普通证件新建和现有卡包编辑均不受上次选择影响。完整类型选择器和拆分菜单共用同一目录。

本地 M3E Canvas 项目标识 `extension-wallet-create-20261021-v2`，可编辑草图和本地 URL 保存在 `docs/design/wallet-create-20261021.m3e.json` / `wallet-create-20261021-url.txt`。草图及真实渲染截图仅留本地，不作为仓库图片交付。
