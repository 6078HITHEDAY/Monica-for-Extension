## 重点修复

自动填充后提交原密码曾错误地弹出“更新 Monica 中的密码”。现在后台在网站、账号匹配后逐字比较密码；完全相同则不提示、不写入，并清理同一页面上旧的待更新候选。密码发生任何实际变化（包括空格和大小写变化）仍进入更新流程。回归覆盖手动输入、内联自动填充、同名账号、不同账号复用密码和刷新导航。

本版同时纳入此前未发布的独立导入导出功能及 Android ZIP/KDBX 互通验证，详见[功能验证记录](../import-export-20261023.md)。

## 范围
