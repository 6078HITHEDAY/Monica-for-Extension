# 底部多选操作栏验证

版本 1.0.101。多选操作栏固定在视口底部，按内容区宽度居中，保留当前配色。通过 ResizeObserver 测量换行后的实际高度，在列表和分页之后预留等高空间及 32px 间距；退出时清理观察器并移除留白。固定层位于管理页尺寸容器外，避免容器改变 fixed 定位基准；导航抽屉和模态对话框打开时禁止背景操作。

隔离 Edge 验证通过两个实际应用用例：75 条合成项目的滚动/分页布局，以及既有多选完整操作回归。布局覆盖普通管理页与 sidepanel 文档、1200/2560/420/320px 宽度、100%/200% 字体、900/950/500/360px 高度。滚动前后操作栏坐标不变；最后一个列表项及分页底边均可滚到悬浮栏上方；窄屏无横向溢出，矮窗口内可滚动访问操作，退出后恢复底部导航和普通布局。

多选回归覆盖长按、右键、空格、Esc、整组密码、批量收藏、传输、取消删除、并发变化拒绝、实际删除、卡包与 OTP、锁定和 Popup 越权拒绝。未访问个人浏览器配置或真实数据；没有启动 Chrome 或 Android 虚拟机。

命令：

```powershell
$env:MONICA_E2E_EDGE='1'
node scripts/e2e-edge.mjs tests/e2e/item-selection.spec.ts tests/e2e/settings-pages.spec.ts --workers=1 --output=.tmp/stable-final-layout-results
```

最终 4 项全部通过（含两项设置页回归）。设置页原先严格要求 `2px` 的焦点轮廓，在 Windows 显示缩放下被 Edge 量化为 `1.6px`；断言改为保留 solid 样式并允许最多一个设备像素的取整差异，没有修改生产焦点样式。

可编辑草图、本地项目链接及实际应用截图保存在 `docs/design/selection-bottom-20261021-*`，仅留本地，不提交图片或草图。未自动化操作原生浏览器侧栏外框。
