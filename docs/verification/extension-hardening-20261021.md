## 交付行为

- 明文 JSON、加密整库备份和历史副本导出：后台重新认证当前主密码或绑定的 Windows Hello，确认会话、完整加密库版本和验证绑定仍一致；旧运行时导出入口拒绝。明文只包含活动未归档项目；整库备份保留完整状态与本地附件。设备密钥且未注册 Hello 时先引导设置保护。
- 剪贴板：默认关闭、按需权限，30/60/120/300 秒；会话存储只留哈希和截止时间，关闭复制页面或后台挂起不取消期限。共享受认证 offscreen 文档核对内容后清理，锁库提前尝试，后来复制的不同文本保留。取消权限或系统状态可能阻止清理。
- 本机恢复检查点：修改前自动保留，15 分钟最多一份、最多三份、总密文 64 MiB。主记录与历史原子保存；空间不足重试不保留历史；普通写入失败均回滚。保护方式变更使旧副本失效。容量接近上限有提示，可重新认证导出或明确确认清理历史。历史可能含已删除内容，不是独立备份。
- 运行诊断：白名单脱敏状态下载，不输出原始错误、项目、站点、服务器、路径或绑定标识。源构建哈希让同版本号的不同 UI/后台拒绝混用；这不是数字签名。构建身份由 npm run build 自动更新。
- 补充主密码/设备密钥差异、云端后台调度与附近同步需要页面打开的条件，以及未完成接收无法安全继续时的备份/保留原设备指引。没有增加不安全的覆盖或丢弃按钮。
- 抽出导出弹窗、剪贴板、容量/恢复和诊断模块；增加英语及六种离线语言文案。CLI 独立词典由 CLI 会话单独检查。

### 调试中暴露的问题

1. 最初 offscreen 空文本选区未真正复制，真实清理失败；改为非空占位选区并在 copy 事件替换为空文本，随后真实 Edge 清理通过。
2. 构建图标扫描器将 Vue 标识 overview/clear 当成图标；重命名组件局部变量，没有为不存在的图标扩大字体。
3. CLI 新模块尚未落盘时构建失败；之后 scoped 词典的48条文案被全局扫描误报，CLI 会话使用显式 cliTr 和独立完整性测试修正；新增测试使用 Object.hasOwn 不符现有 TS lib，改为 hasOwnProperty.call，没有抬高全局编译目标。
4. 性能探针的旧 popup CSS 选择器失效，改为真实 searchbox；浏览器 _favicon 虚拟资源不在 dist，改为单独计数，不忽略其他缺失文件。
5. 首次360px截图撞上侧栏关闭动画，后续截图禁用动画并检查关闭状态，避免把遮挡画面作为验收证据。

## 实际边界与后续

- 首次申请可选剪贴板权限的浏览器原生弹窗仍需人工点击验收。自动测试将仅这两个权限在临时测试 manifest 中预先授予，生产 JavaScript 不变，生产 manifest 仍是 optional_permissions。系统剪贴板历史、跨设备副本、浏览器完全退出后清理不在保证范围。
- 本机恢复副本只有当前库仍可解锁时可导出，不提供主库损坏后的锁屏修复；浏览器配置删除会同时丢失当前库和本机副本。独立加密备份仍必要。
- 大型 App/background/secure service 及完整 manager 明文快照仍需逐步缩减；本轮完成有明确边界的模块拆分，不宣称整体架构重构完毕。
- 第三方审计、商店签名发布、真实物理手机和家庭网络故障矩阵没有在本轮完成。用户已验证的系统 Passkey保持接受。之前 Android公共AVD/Edge19轮互通证据见 nearby-sync-stress-20261021.md；没有冒充新增物理设备测试。
- 一般重启后的ZIP扩展掉加载仍没有明确复现条件；运行诊断和固定解压目录指引改善可诊断性，不能宣称已根治未知故障。
