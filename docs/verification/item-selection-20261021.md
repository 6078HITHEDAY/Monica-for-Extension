# 项目多选验收（2026-10-21）

## 行为

普通列表、钱包与验证码卡片支持主键长按 550ms 或右键进入多选，并选中当前项目；页面提供显式「多选」入口。进入后点击项目或勾选框切换选择，可全选／取消当前页，最多选择 200 个项目。支持批量收藏、取消收藏、传输及移到回收站，Esc 退出；切换分类、搜索、筛选或锁库清除选择。普通点击、内嵌编辑和菜单沿用原流程，移动超过 8px、滚动、失焦、拖动或指针取消会中止待触发的长按。

收藏与删除按完整密码项目展开，使用现有密码源与数据库作用域，包含组内已归档成员但不跨库扩展。后台只接受管理页调用，校验完整成员版本和明确删除确认后单次加密保存；任何成员变化、存储失败或锁库均不会部分保存。远端更改复用现有同步队列，未同步的新建后删除沿用队列合并规则。回收站及归档页不开放此轮多选。

传输复用现有预览／确认流程，初始范围和勾选来自所选项目；后台继续展开完整密码项目和既有依赖，并遵守现有传输上限。
