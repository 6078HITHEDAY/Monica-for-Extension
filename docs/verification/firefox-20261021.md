# Firefox 桌面兼容验证（2026-10-21）

版本：1.0.101。环境：Windows、Firefox 155.0.1、geckodriver 0.36.0。最低 Firefox 153，由原生页面 documentId 的可用版本决定。

## 实际浏览器验证

`scripts/firefox-acceptance.mjs` 对生产构建使用独立配置，验证以下流程：

- 扩展启动、加密库初始化、增删改查、批量收藏、过期写入拒绝、导出重新认证及错误密码拒绝。
- 内置 MDBX WASM 建库、写入、揭示、锁定、重开；文件完整导出、SHA-256、分块导入和重开。
- 独立打开引擎页面和伪造运行时连接均被拒绝，正常引擎继续工作。
- 网页输入框真实键盘选择和自动填充；同源页面导航后，旧 documentId 的填充被拒绝。测试先激活目标标签，排除因非活动标签导致的误判。
- Monica Passkey 创建及登录，clientData 的网站来源；锁定后进入独立验证窗口，错误密码拒绝、正确密码解锁并继续注册。
- 锁定阻止读取，错误解锁拒绝；实际退出并重启同一任务配置后，解锁会话丢失，加密本地库和 MDBX 数据保留。

`scripts/firefox-ui-acceptance.mjs` 验证真实页面中的右键多选、Esc、OTP 渲染、更新检测的五种结果与安全链接、窄窗口布局、由实际点击打开的 Firefox 侧栏和有效的附近同步管理租约。

其余测试在生产代码旁使用明确的测试替身：

- 剪贴板：仅以合成内存内容运行生产告警/摘要比较/清除逻辑，保留用户后续复制的不同内容。没有读取或写入真实系统剪贴板，操作系统实际权限提示与粘贴行为未自动化验收。
- 浏览器验证器转交：在测试副本中、生产 MAIN 脚本绑定前替换原生凭据接口，仅返回合成凭据；验证锁定/解锁状态、Esc 和转交前后 AbortSignal。没有调用真实系统凭据选择器或枚举个人 Passkey。
- 本机通信：临时随机名称的 Mozilla 注册启动真实扩展辅助程序和更新后的 CLI 辅助程序。进程 appdata、CLI 可执行文件位置均隔离到任务配置，CLI 返回空数据库和未解锁状态；完成后删除测试注册，不改生产注册。
- OneDrive：真实 Firefox identity API 的回调地址与精确允许列表相符；授权交换和篡改拒绝使用合成 HTTP 响应。

## 其他检查

Windows PowerShell 5.1 安装脚本执行测试使用注册表替身，覆盖 Firefox 精确 ID、Edge/Chrome 共存、拒绝非法 ID、卸载及清单数组格式。

单元测试初次运行 4258 通过、25 项遇到默认高并发的 5 秒超时；没有断言失败。七个涉及超时的文件在最多两个 worker、30 秒时限下全部重跑通过（211 项）。合并两轮覆盖原有 338 个文件、4283 项测试；后续新增 OneDrive Firefox 回调测试另行通过。

Edge 17 项实际回归全部通过，包括输入框填充、更新检测、多选、MDBX 引擎/服务工作线程恢复与锁定 Passkey。TypeScript、双构建清单/本地资源检查、安全静态审计及 Firefox 新增边界测试通过。

本地机器证据在 `.tmp/firefox-acceptance/{evidence.json,ui-evidence.json}` 与 `.tmp/firefox-*.log`；截图仅留本地，不作为公开文档图片。

## 限制

没有读取个人 Firefox 配置、真实密码存储或系统剪贴板；没有运行 Android 虚拟机。真实云账户登录、Windows Hello/手机扫码/安全密钥硬件认证、其他桌面操作系统，以及跨 Android/浏览器的整套同步流程不属于本次 Firefox 实际验收。已有同步未完成项目仍按原记录保留。AMO 元数据、Mozilla 签名及正式发布尚未执行。
