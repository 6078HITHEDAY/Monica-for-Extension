# 1.0.101 首个正式版发布验证

日期：2026-10-21。扩展版本 1.0.101，Windows x64 可选助手 0.1.4。首个正式版承接 0.1.x 预览历史；发布标签为 `v1.0.101`。新建分类、卡面附件、多选和底部悬浮操作栏等本轮改动均纳入本版。

Edge 核心矩阵覆盖卡面附件、新建分组与旧支付记录、重新认证导出、恢复检查点、剪贴板生产路径、更新检测、导航抽屉、Passkey 原生转交、后台重连、设置布局、IndexedDB 配额故障及卡包保存（16 项）。多选两项覆盖手势/键盘、并发保护、删除与传输，以及普通页和侧栏文档的底部固定、分页、320–2560px、200% 字体及矮窗口留白。详见[底部多选栏验证](selection-bottom-20261021.md)。

额外 13 项 Edge 回归覆盖归档／回收站权限、按页新建菜单、主密码轮换与整库恢复、备份密码不一致拒绝、设备密钥恢复与无 Hello 导出拒绝、密码源视觉／菜单、设置语言名称及六种语言的离线全导航、200% 字体、嵌套备注编辑和锁定填充。

补充矩阵覆盖网页输入框填充（12 项）、保存/更新/取消密码（5 项）、ES256 与 Bitwarden Passkey 注册/登录/取消/删除（7 项）、内置 MDBX 引擎持久化/回滚/重启/600KB 附件与独立原生往返（1 项）、真实附近同步协调器与 MDBX 双向编辑（1 项）、CLI 默认关闭/启用/禁用（1 项）。

MDBX 引擎验收先前依赖一个未入库的临时 probe EXE。本轮将其替换为生产 Native Client 与隔离助手进程，实际打开浏览器导出，验证精确 JSON 数值、密码、原始 Passkey 私钥哈希及对象 ID，再由原生修改并导出完整备份，重新回到浏览器验签与核对内容。没有跳过独立原生读回。

## 失败与修复记录

- 首轮 npm 转发没有应用并发/超时参数，且和原生密码派生测试同时运行，165 项超时。保留初次日志；最终直接运行 Vitest CLI，全部 4,305 项通过。
- 设置焦点断言受 Windows 显示缩放的设备像素取整影响，2px 计算为 1.6px。保留 solid 轮廓检查，允许最多一个设备像素差异；两项设置用例复测通过，未改动产品焦点样式。
- 旧密码保存夹具未沿用 Edge 与短路径配置，初轮三个 setup 失败。改为共用浏览器启动器后，五项全部使用隔离 Edge 通过。
- MDBX 压力首轮浏览器连接中断；第二轮明确暴露缺失临时 probe，补齐可复现原生读回后最终整条流程通过。原始日志及 trace 均保留在本地。
- GitHub 全新环境的 CI/CodeQL 在离线 WASM 构建前漏取宿主平台依赖（`cpufeatures`）。预取改为锁文件内全部目标平台依赖，保留随后 `--locked --offline` 构建和所有版本固定要求。发布草稿在修复前保持未公开。

- Windows 全新检出的 CRLF 换行与 Linux LF 导致构建标识不同，生成文件使正式打包触发脏源码保护。构建标识只对文本归一化换行，二进制逐字节保留；新增三项实际脚本回归验证跨换行一致、源码更改可检出和二进制字节变化可检出。
- Linux 全量 E2E 发现旧脚本仍要求 CLI 默认入口、支付方式新建入口及旧导出按钮；按当前需求更新脚本，保留导出重新认证和设备密钥无 Hello 拒绝导出检查。归档恢复后的列表定位改为当前卡片结构，多语言编辑备注走真实的嵌套编辑页。
- 多语言 200% 字体揭示顶部“多选／批量传输”按钮被结果计数挤窄；浏览工具栏允许换行，按钮保留自然宽度。韩语在 200% 字体、320×480 窗口选择语言时，默认选项面板高于视口，顶部选项无法点击；选项面板增加视口高度上限，六种语言完整复测通过。

## 范围

本轮使用隔离合成数据，不访问 Chrome 个人窗口、个人浏览器配置或真实密码库，不启动 Android 虚拟机。之前 Android 1.0.321 的互通与压力测试见[已有报告](nearby-sync-stress-20261021.md)，不冒充本轮再次运行。没有执行单条完整 `release:check`，而是按本机环境拆分运行上述检查；没有全量运行所有 E2E、真实 CLI 写入、实体手机、真实云账户或硬件认证。Firefox 永久安装仍需 Mozilla 签名，本次公开附件不包含未签名 XPI。

本地日志与发布读取结果在 `.codex-tasks/20261021-first-stable/` 和 `.tmp/stable-*`；Canvas 草图和实际截图仅留本地。发布时显式列出插件 ZIP/校验文件及可选助手 ZIP/校验文件，不上传整个 release 目录或个人数据。
