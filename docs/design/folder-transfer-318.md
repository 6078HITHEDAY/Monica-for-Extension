# 文件夹筛选与传输

沿用青绿 M3E 和系统字体。数据库与文件夹连续列表，12px边距、24px外圆角、4px相邻圆角；完整路径与选中状态可见。Passkey/Steam页面的传输入口继承当前搜索与数据库/文件夹范围（包含分页外匹配项），后台预览再展开必要关联项目。复制保留源记录，受限项列出原因并允许取消或跳过。传输目标统一选择本地库或已解锁MDBX，其他后端仍在接入。本地保存与MDBX使用相同连续分组布局；单选文件夹、复制/移动和预览位置保持一致。附件沿用现有管理弹窗，显示文件名、大小与下载/替换/删除。保留分类时按来源数据库分别解析文件夹，不能跨库混用同名/同ID目录。 复制/移动选项在窄屏或大字号下排列为两条完整行，图标与标题同排、说明自然换行，避免两列挤压。 320–420px传输弹窗减少叠加留白：正文8px、分组12px、条目8px，保留复选框触控面积和图标，让项目名称与来源有足够行宽。
