## 2026-10-11 页面入口与来源目录隔离

Passkey/Steam 入口复用现有 MDBX 预览、确认和恢复流程；目录和搜索范围在打开时固定，其他窗口删除候选后会移除对应选择，锁定后清除临时范围。Steam 登录项通过其真实登录记录传输，不把界面投影误存成另一条记录。

修复来源目录统一合并导致跨数据库同 ID 文件夹相互覆盖的问题：每个项目使用所属来源的独立目录表。目录读取失败只阻止该来源及其关联组，不再中断其他独立项目；移动提交绑定也不访问已被阻止的来源。保留原分类时，如果父目录缺失或循环，则要求修复或明确选择目标位置，不默默缩短路径。

共用 Bitwarden Cipher 的多个密码/Passkey/验证码不能通过逐项跨库移动删除原 Cipher；在预览中阻止，复制继续允许。完整共享记录事务、本地/KeePass/Bitwarden 目标、持久化后的源清理和相应真实后端验收仍在后续范围。
