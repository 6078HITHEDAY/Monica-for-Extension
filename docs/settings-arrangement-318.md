# 设置分组、直接操作与紧凑布局

2026-10-11，开发构建 0.1.37。替代此前“每个设置都进入二级页”的安排，不改变设置存储及密码库操作协议。

## 信息安排

| 分组 | 首页直接操作 | 保留的二级页 |
| --- | --- | --- |
| 通用 | 界面语言、显示模式 | 配色：六套配色预览与选择 |
| 同步与填充 | 自动同步、表单旁自动填充 | 自动填充排除项：维护列表及保存/取消 |
| 密码库与安全 | 展示当前保护方式与 Hello 注册状态 | 解锁与保护；备份与迁移 |

二级入口从十个减为四个。Windows Hello 与更改保护方式合并到同一页，加密备份/恢复与明文迁移合并到同一页。配色页不再重复显示模式，安全说明放回相应操作旁，不占独立导航项。明文导出附近明确说明文件含有密码等敏感信息。

返回保留焦点及滚动位置。离开保护页清空未提交的密码；离开备份页清空恢复密码和文件选择。开关保存失败保留旧值并允许重试，保存中阻止重复操作。没有增加中间确认步骤，原有备份加密密码、恢复校验和 Hello 确认仍保留。

## 紧凑布局

采用连续分组的 M3E 行：外侧 24px 圆角、相邻 4px 圆角、4px 行距、20px 组距、横向 16px/纵向 8px 内边距。语言和显示模式去掉空白提示占位，标准字号行高由约 108px 降至 72px，配色行同为 72px。图标使用统一的 40px 容器。

表单内部不再叠加左右留白；在 320px、200% 字号下保留完整语言名称。开关说明占满行宽，避免被放大的开关挤成很窄的文字列。高度随字号和换行增长，不用固定高度裁切内容。

语言/显示模式下拉框去掉内层胶囊聚焦边框和单独的悬停底色。由设置行统一提供悬停和展开反馈，鼠标选完并移开后恢复普通底色；Tab 键定位时只在整行边缘保留 2px 焦点提示，菜单选项仍有独立键盘提示。系统高对比度使用 Highlight 色。普通输入框的验证边框和错误状态不变。

设计记录：[本地 M3E Canvas 草图](design/settings-arrangement-318.md)，可编辑 JSON 为 `design/settings-arrangement-318.m3e.json`。三个页面均已导入本地编辑器并预览；真实明暗模式及窄屏页面已另行检查。草图初次缺少文本节点必需字段、字号误用宽度，均修正后重新预览，未把失败画布作为完成证据。
