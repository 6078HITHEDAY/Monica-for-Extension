# KeePass 批量传输目标与恢复

2026-10-12，浏览器插件开发构建 0.1.37，接续 `99b1427` 的文件事务基础。本块接通界面、运行时、远端发布及加密密码库索引更新；完整 Android 对齐仍未完成。

## 用户操作

- 密码源卡片与现有批量传输入口可选择 KeePass 本地文件、WebDAV 或 OneDrive 目标，并选择原生文件夹。复制展开关联项目，同库移动保留原条目身份；跨库移动暂在预览中阻断。
- 预览重新读取来源字段、附件及路径，执行前核对其内容。读取失败或不支持的 Passkey 按关联组阻断，不拆散同一组；无法无损表示的字段、原生格式降级和不完整关联拒绝写入。
- 未完成的传输在目标下方显示恢复入口。只有没有文件回执的操作可以取消；已经保存的文件通过原操作恢复结果。
- 本地文件保留在加密工作副本中，结果提示导出并保存 KDBX。WebDAV/OneDrive 在带 ETag 检查的发布成功后完成；独立远端编辑可合并，结构或字段冲突停止覆盖。

## 保存及安全边界

加密密码库先保存操作意图，KDBX 文件与加密回执再原子写入。发布之后重新读取当前完整数据库，最后在同一密码库事务中更新索引和完成状态。恢复不依赖尚在内存中的来源草稿，不回放旧回执快照覆盖后来编辑或删除；后续待同步的本地编辑和其他密码源项目继续保留。

来源/目标绑定和文件内容指纹均参与校验。目标变化、锁定、未保存的后续原生修改会停止恢复；锁定向正在上传的请求传递取消信号。上传中断仍可能已经在服务器提交，由回执及远端版本核对负责恢复。最终索引事务保留届时最新的 OneDrive 连接令牌，避免异步刷新被旧发布快照覆盖。

预览最多保留四份、五分钟后失效、锁定清空。持久传输记录保存在加密库中，达到 1000 条时拒绝新增，不静默丢弃防重放信息。附件沿用认证读取、实际大小及 SHA-256 校验，单批总量上限 16 MiB。新恢复/取消消息仅允许管理页调用，普通弹窗不能调用。临时探针已移除。

本轮修复两项实际格式问题：

- KDBX 3.x/4.0 不序列化 `previousParentGroup`，库却会在移动后将其留在内存。内容比较现在只在这些旧格式的原生条目/组上忽略该属性，4.1 保留校验，同名自定义字段仍参与比较。
- KDBX PEM 读取会把 Base64URL 私钥规范化为 Base64。迁移核对私钥、公钥和用户句柄的实际字节，而非编码文本；凭据 ID 核对规范化字节身份。未改变私钥内容、注册标志或 Android 的零计数策略。

## 尚未覆盖

OneDrive 分支使用真实远端会话服务及合成文件客户端，未进行真实 Microsoft 登录/云端账号验收。本轮没有 Android 编辑、构建或设备操作，没有真实站点登录；独立签名通过不等于 Android 系统凭据管理器验收。Bitwarden 目标、外部来源持久删除、更多原生字段/后端矩阵和附近设备同步仍待完成。原目录 `dist` 已重建，未推送、打标签或发布新版本。
