## 复现与修复

带文件夹的密码项目在准备移除时会先同步草稿。普通同步解码写入回执时遗漏文件夹名称，使本地 `categoryName` 暂时消失；后续准备检查因此将正常回执误判为新的本地编辑，自动撤销移除。真实 Edge 首轮复现返回 `cancelled`，请求序列只有同步和一次更新，尚未复制或删除 Passkey。

本批修正三处目录投影：

- 普通更新及回收站核对使用最终回执中的文件夹 ID 查找已解密目录名称，连同登录项和关联凭据一起回写。本地并发内容检查保持原有严格语义。
- 准备期恢复收养已确认副本时，解密和校验回读目录列表，保留文件夹 ID 与名称，重启后仍可读取。
- 登录项投影出的验证码继承目录名称；不改变 OTP 参数和备注。

原凭据 ID、私钥、远端文件夹 ID及签名计数没有修改。Android 产品代码及零计数策略未改。未新增界面布局或运行时命令；沿用已保存的[本地 Canvas 设计](design/bitwarden-removal-318.md)和现有管理页操作。
