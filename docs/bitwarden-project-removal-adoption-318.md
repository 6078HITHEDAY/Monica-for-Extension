# Bitwarden 项目移除：准备协调与本地一致保存（2026-10-09）

本批完成内部协调器的正常成功流程和重启恢复验收：同步项目及关联凭据、复制并核验共享附件、持久化删除意图、逐条删除、权威回读，以及一次加密保存本地结果。**管理端入口尚未开放，完整 Android 互通尚未完成。**版本仍为 0.1.37，未提交、发布、推送或打标签。

## 实现

- `BitwardenPasswordProjectRemovalCoordinator` 组合真实持久同步、附件服务和既有核验/事务引擎。删除意图保存后不再调用普通同步。调用方仍需持有来源操作队列；运行时接入留待后续。
- 共享附件从认证下载取得原文大小和 SHA-256，逐项复制到保留成员并重新下载核验。相同内容的现有副本可复用；不同内容的同名文件会中止准备，原文件保留。稳定的复制操作 ID 与附件恢复日志共同避免重复上传，恢复时也会完成已存在副本的未完成回执。
- 加密删除日志冻结关联 TOTP/Passkey 的本地身份和完整快照。未完成子项同步、冲突、使用或编辑变化会阻止采用旧结果；不会为了完成删除覆盖新数据。
- `completePasswordProjectBitwardenDeletion` 同时保存登录及关联凭据、原始 Cipher 封装、来源会话、队列清理和 completed 状态，只有一次加密写入。保持本地项目/凭据 ID，保留其他来源引用、无关记录及本地 Passkey 使用历史。网络请求不在密码库写锁内执行。
- 回读再次匹配冻结的原始 Cipher 摘要、封装摘要和完整凭据集合，拒绝缺失、重复或额外子项，以及内容、项目身份、文件夹/集合、来源修订号不一致的投影。
- 修复现有 Bitwarden 解码问题：回收站或归档密码的独立验证器投影现在继承父项状态；恢复后清除相应状态。HOTP 原有小整数表示保持不变。
